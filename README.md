# BridgeLabz Database Training

This repository contains all the projects and assignments completed during my **BridgeLabz Database Training Program**.

Each project is organized into a separate branch with its own source code, documentation, and README.

---

# 📂 Repository Branches

| Branch | Description |
|--------|-------------|
| **dbms** | SQL practice, database concepts, employee payroll database, greeting database, queries, triggers, functions, procedures, and review files. |
| **Jdbc_Java_Raw_Greeting_Project** | Greeting application developed using Core Java, JDBC, and PostgreSQL. |
| **Jdbc_Java_Raw_EmployeePayRoll_Project** | Employee Payroll Management System developed using Core Java, JDBC, and PostgreSQL. |
| **Jdbc_Java_Maven_Template_Greeting_Project** | Greeting application developed using Spring Framework, Spring JDBC Template, Maven, and PostgreSQL. |
| **Jdbc_Java_Maven_template_Employee_PayRole_Project** | Employee Payroll Management System developed using Spring Framework, Spring JDBC Template, Maven, and PostgreSQL. |

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ArpitGupta0212/BridgeLabz_Database_Training.git
```

Switch to any project branch:

```bash
git checkout <branch-name>
```

Example:

```bash
git checkout Jdbc_Java_Maven_Template_Greeting_Project
```

Each branch contains:

- Complete Source Code
- Project-specific README
- Database Scripts (where applicable)
- Maven Configuration (where applicable)
